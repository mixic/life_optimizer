Classify the last six deduction rules, and gate St. Gallen's conditional one

Pushed classification coverage to 100% and made it an invariant. Six real deductions
were being ignored; all six are now classified, and the build fails if a refreshed
export adds one that is not. Test count rises from 203 to 206.

The six, and why each was missed

  Abzug Krankenkassenprämien, Verheiratete / alleinstehende Personen /
    minderj. Kind / vollj. Kind in Ausbildung
      Fribourg publishes health-insurance premiums under their own label rather
      than as `Versicherungsprämien`, so no prefix matched. Classified as
      InsurancePremiums -- they are ceiling-only, the same shape as the rest of
      that family, and exactly one adult variant applies per household (4,810 for
      a single taxpayer, 9,620 married).

  Abzug Versicherungspärmien und Sparzinsen, Verheiratete, beide ohne Beiträge
    Säule 2/3a
      AN UPSTREAM TYPO: `Versicherungspärmien`, missing the `s`. No
      correct-spelling prefix can match it. Listed explicitly rather than loosened
      to a substring, which would start catching labels nobody has seen yet.

  Kinderausbildungskosten Eigenbeitrag
      St. Gallen, a flat CHF 3,200, and the one that needed more than a
      classification: it is conditional on the taxpayer actually making such a
      contribution. Applying it to any household with a child would deduct the
      amount unconditionally, in a canton the default output path never reaches.
      Gated on a new `Household::education_contribution`, exposed as
      `--education-contribution`.

Verified end to end: SG married with two children and a CHF 3,200 contribution
reports CHF 16,400 of cantonal deductions against CHF 13,200 without -- the
difference being exactly the Eigenbeitrag.

Coverage is now an invariant, not an audit

`every_deduction_rule_is_classified` asserts that no deduction-kind rule lacks a
category. A generated table cannot be hand-audited every time the export is
refreshed, so the test asserts the property instead, and reports the offending
label when it fails. That is how the Jura typo surfaced.

Also

  - `Commands::Optimize` is boxed into a new `OptimizeArgs` struct. The enum's
    largest variant reached 299 bytes once the household-fact flags were added, and
    a plain enum is as large as its biggest variant, so every `Commands` value paid
    for it. The refactor drops a clippy warning rather than silencing it.
  - SWISS_TAX_DATA.md records the six rules, the typo, and the per-category rule
    counts as a check that no family collapsed to zero.

Verified: 206 tests pass, clippy back to 9 pre-existing warnings, and no CLI golden
changed.
