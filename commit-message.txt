Show the imputed rental value as an income addition in the comparison output

The widened engine reports a homeowner's Eigenmietwert as an income ADDITION as
well as a deduction base, so the comparison now prints it -- with an explicit plus
sign, because every other figure in that list is a deduction and a bare number
between two minus-figures would read as one.

Nothing else changes: the household is not yet constructible as a homeowner from
the CLI, so this branch is inert until flags exist for it. It is printed anyway so
the field cannot silently disappear from the output if that changes.

Also visible in this commit is the effect of the wealth-deduction fix on a plain
tenant: Zurich's sourced total falls from CHF 12,600 to CHF 12,300, because
`Abzug Vermögensverwaltungskosten` (0.3% of income, capped at 6,000) is no longer
deducted from a salary.

Verified: 194 tests pass, clippy unchanged at 9 pre-existing warnings.
