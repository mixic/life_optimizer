Add flat-rate cantons and fix the tax-basis label

Supports the two cantons that levy a uniform percentage rather than a
progressive scale, bringing priceable cantons from 20 to 22, and fixes a display
labelling bug. Test count rises from 154 to 158.

Flat-rate cantons (Obwalden, Uri)

OW and UR publish a single `Steuersatz %` (1.8% and 7.1%) instead of a band
table, so a parser that requires a band column found nothing for them. Both are
the cantons the finpension article identifies as having a uniform rate.

BaseScale gains `flat_rate_percent` and `is_flat_rate()`. The imported table for
these cantons is a single 0%-at-0 floor, so the band machinery contributes
nothing and the percentage is applied as `income x rate x Steuerfuss`. Emitting
the rate as a one-band schedule would have worked arithmetically but would
misrepresent the tariff as progressive.

Verified: OW at CHF 100,000 gives 12,978 = 100000 x 1.8% x (3.35 + 3.86), and the
effective cantonal rate does not change with income, which is what distinguishes
a flat canton. The test also asserts that a band canton (ZH) IS progressive, so
the two paths are contrasted rather than one merely exercised.

Display bug: the tax-rate line claimed Bern

`print_optimal_result` printed "Tax Rate: 13.0% (official Bern tax only)"
unconditionally, which became false the moment the two-level model started
pricing other cantons. It is now supplied by the caller:

  OW  Tax Rate: 13.0% (OW flat 1.8% x Steuerfuss)
  ZH  Tax Rate:  9.9% (ZH ESTV scale x Steuerfuss)
  BE  Tax Rate: 14.5% (official Bern table)

This was nearly invisible: OW's correct 13.0% coincides with the hard-coded Bern
figure, so the label looked right while describing the wrong canton. The CLI also
now distinguishes a flat rate from a scale in the "Tax basis" line.

Open item found while testing: Steuerfuss vintage lags the scale vintage

Scales are imported from 2026 exports while Steuerfuesse are read from the 2024
row of the ESTV workbook. Sarnen's cantonal multiplier moved 3.35 (2024) to 3.25
(2026), so OW is priced with the 2024 figure. That was discovered by a test
failing on a 180 CHF discrepancy, and is now recorded by
steuerfuss_vintage_is_recorded rather than papered over.

The same check showed Aargau's hand-entered Steuerfuss is 1.11 while the workbook
carries 1.12 for 2024, so that value has its own provenance. The test asserts the
figure in use, not a cross-check against the workbook, and says so.
