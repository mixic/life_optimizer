# documents/

The arguments this tool came out of.

They are here rather than at the repository root because a person deciding whether to drop to 80%
should not have to scroll past a treatise on Plato to find the calculator. They are not a separate
project: each one is the same question — *what is a working life worth, and to whom* — asked at a
different scale, and the tool is what keeps them honest about numbers.

Nothing in this directory is needed to run the tool. If you are here to compute something, start at
[`../README.md`](../README.md) or [`../QUICKSTART.md`](../QUICKSTART.md).

## A note on why these are not a separate repository

An external review recommended splitting them out, and the answer is in
[`../CRITIQUE_RESPONSE.md`](../CRITIQUE_RESPONSE.md) §4. The short version: the review was right
about the presentation and wrong about the connection. The essays are the argument the calculator
exists to make concrete, and the calculator is what stops the essays from being unfalsifiable. Same
repository, different front door.
